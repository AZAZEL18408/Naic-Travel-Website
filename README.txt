WANDERLY — CINEMATIC TRAVEL WEBSITE TEMPLATE
================================================

WHAT'S INCLUDED
- index.html: main travel landing page with all 10 assignment sections
- style.css: complete responsive styling and animations
- script.js: loader, scroll progress, reveal animations, mobile navigation, Cavite focus interaction
- destinations/: four sample destination detail pages (Tagaytay, Indang, Kawit, Ternate)

HOW TO RUN
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Install/use the Live Server extension.
4. Right-click index.html > Open with Live Server.

CUSTOMIZE
- Replace the sample images (Unsplash URLs) with your own destination photos.
- Edit the descriptions, attractions, food, accommodation, travel expenses, and contact details.
- Add more destination pages by copying one of the HTML files in destinations/.
- Update the destination card links in index.html.

MAP NOTE
The Philippines map in this starter is a stylized CSS illustration, not an accurate geographic map.
The Cavite focus marker is an interactive demo. Replace the CSS island shapes with a licensed Philippines map image/SVG and position the Cavite hotspot accurately for your final submission.
The municipality chips are starter links; add detail pages and exact destination information as needed.

TECH
HTML5, CSS3, Vanilla JavaScript. No build tools or npm installation required.
Google Fonts and Unsplash sample photos require an internet connection.


16-BIT ARCADE EDITION
The theme is now retro 16-bit / pixel arcade inspired: pixel fonts, chunky borders, HUD-like labels, pixel image rendering, stepped transitions, and game-like colors.
